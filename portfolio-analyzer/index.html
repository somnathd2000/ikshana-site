Log into Fidelity through a secure consent portal

Your Fidelity credentials should be entered only on Fidelity/SnapTrade screens. This app asks a backend for a short-lived connection portal URL, then imports holdings after consent.

Setup needed
Setup needed: add your SnapTrade API credentials locally, then Connect Fidelity will open the secure consent portal.

SnapTrade Setup

1. Create local secrets file

Create portfolio-analyzer/.env from .env.example and fill in your SnapTrade values.

2. Restart local server

Stop and restart node server.js, then return to this page.

3. Connect Fidelity

Click Connect Fidelity. You will enter Fidelity credentials only in the external consent portal.
